# Anglicizmy a kalky v slovenčine

Zoznam kalkov pre slovenské texty. Ku každej odrážke patrí regex
v `calques.json` v tej istej zložke; test v repe stráži zhodu kľúčov aj to, že
regex chytí svoju ukážkovú vetu a minie protipríklad.

**Nový kalk pridávaj skriptom `scripts/add_calque.py --lang sk`**, nie ručnou
editáciou.

Český zoznam žije zvlášť v `../cs/kalky.md`. Delia sa zámerne: rovnaká
anglická väzba má v každom jazyku inú prirodzenú náhradu. Slovenský text navyše
rieši bohemizmy, tie sú v `bohemismy.json`.

## Štruktúrne kalky

Doslovný prevod anglickej väzby. Znie gramaticky správne, ale neslovensky.

- „beží pred realitou" (z „to run ahead of") → **„predbieha realitu"**

- „vnútri sedí / pracuje X" (z „inside sits/works") → **„vnútri nájdete X" / „základom je X"**

- „nesie krytie / rating" (z „to carry a rating") → **„má krytie" / „je odolné podľa"**

- „výhoda leží v cene" (z „the advantage lies in") → **„výhodou je cena"**. Abstraktná vec po slovensky nikde neleží, jednoducho niekde je, alebo ju rovno popíšeš slovesom.

- „varianta sadne do malého bytu" (z „to fit / to sit well") → **„hodí sa do malého bytu"**

- „úspora stojí na bonuse" (z „to rest on / to be built on") → **„úsporu prináša bonus"**

## False friends

Slovo znie v angličtine aj slovenčine podobne, ale znamená niečo iné. Doslovný preklad je vecná chyba, nielen štylistická.

- „eventne" (z „eventually") → **„nakoniec" / „napokon"**

- „patetický" (z „pathetic") → **„úbohý" / „žalostný"**. Slovenské „patetický" znamená pátosom nabitý, nie úbohý.

- „seriózny problém" (z „serious") → **„vážny problém"**. Slovenské „seriózny" znamená dôveryhodný; seriózny partner áno, seriózny problém nie.

- „kontent" (z „content") → **„obsah"**

- „konkurencia dostáva latku" (z „to set the bar for the competition") → **„konkurencii nastavuje latku"**

- „vrstvu vyhadzuje von / drops the layer" (z „drops/throws out the layer") → **„je bez X / vynecháva X (neživotná vec nemôže vyhadzovať)"**

- „drží (nižšiu|vyššiu) cenu / holds a lower price" (z „holds a lower/higher price") → **„má cenu / ponúka cenu (drží sa pri cene, nie cenu)"**

- „tlačidlo / konektor sedí na hrane" (z „the button sits on the bottom edge") → **„tlačidlo je na spodnej strane"**

- „čítačka vysiela pole" (z „to emit a field (CZ „vysílá pole“)") → **„čítačka vytvára / vyžaruje pole"**

- „história hľadania" (z „search history / historie hledání") → **„história vyhľadávania"**

- „Maj pekný deň" (z „have a nice day") → **„Pekný deň! / Želám pekný deň"**

- „orchestrovať služby" (z „to orchestrate") → **„riadiť / koordinovať / organizovať"**

- „dizajnérska kolaborácia" (z „collaboration (brand collab)") → **„spolupráca / spoločná kolekcia"**

- „diseminácia výsledkov" (z „dissemination") → **„šírenie / zverejnenie"**

- „na konci dňa (= napokon)" (z „at the end of the day") → **„napokon / v konečnom dôsledku"**

- „to spraví rozdiel" (z „to make a difference") → **„to niečo zmení / to pomôže"**

- „kontrolovať osvetlenie (= ovládať)" (z „to control") → **„ovládať / riadiť"**

- „oveľa komplexnejší (= zložitejší)" (z „far more complex") → **„oveľa zložitejší"**

- „evidencia ukazuje (= dôkazy)" (z „the evidence shows") → **„dôkazy ukazujú / dáta naznačujú"**

- „aplikovať sa na pozíciu" (z „to apply for a job") → **„uchádzať sa o miesto / podať si prihlášku"**

Zoznam doplňuj, jakmile na další kalk narazíš.
